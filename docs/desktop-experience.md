# 宽屏用户端适配

本 PR 接续食堂概览 PR #9，单独覆盖 Web 桌面和平板布局。

- 地图：所有选中地点直接打开完整详情面板；长内容内部滚动，关闭后保留小卡上的详情入口。详情与小卡不重复出现，关闭按钮不覆盖收藏/导航。侧栏在中等宽度收缩。
- 评分：搜索侧栏补入口，桌面校车评分提前到页头下方。宽屏使用原生 dialog 居中显示，支持焦点约束、Escape/背景/关闭按钮退出；移动端仍使用底部弹层。提交协议和按功能隐藏策略不变。
- 楼层页：≥1024px 使用平面图与本层设施/照片并排的工作区；无图时仅显示设施列表。平板/手机保持列表与平面图切换。长楼层名使用自适应宽度按钮。
- 平面图：鼠标滚轮、拖动和缩放按钮继续可用；新增「适应窗口」及 + / - / 0 键盘操作。图源变化使用独立 keyed canvas，避免缓存图片 onLoad 被初始化 effect 清空尺寸。
- 食堂详情：≥1024px 供餐/本层设施与商户分栏，本层图片位于底部网格；窄屏继续纵向展示。

验证使用 staging 已有就餐测试数据。评分提交在浏览器中 mock，未写入远端评价。

验证结果：`npm run test:all` 739/739，通过类型检查及生产构建。Playwright 验证 1440/1024/768/390px、1024×600 矮视口，评分 mock 提交与持久化、Escape、楼层跳转、两栏边界、滚轮缩放、鼠标拖动、键盘缩放/复位、连续三次缓存图片刷新、无图楼层回退均通过，无业务 pageerror。

独立审查修复：楼层长说明放到右侧可滚动面板，确保短屏平面图高度；校车评分使用稳定组件实例，跨1024px断点不丢提交，成功立即持久化且感谢态保持。独立 reviewer 已复测4项原发现全部闭环，含 PR9 同日轮询/跨日清理、全部设施未分层项。完整验证741项测试通过。
