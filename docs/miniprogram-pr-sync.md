## 就餐规则与界面

- tab 标题「就餐」，餐具图标；页面标题「校内就餐」，与校车页标题尺寸一致。校外切换继续隐藏。
- 列表按宝山、嘉定、延长分组；定位所在校区提前。食堂和楼层可进入详情，地图按钮通过现有 pending-map-poi 通道定位，关闭地图详情返回就餐 tab。
- 楼层与商家骨架来自 release；就餐时段、校历日型、开放安排与商家营业状态从 live API 获取，每 30 秒刷新，隐藏页面停止轮询。
- 工作日无安排按默认餐别计算；所有日型命中安排均按楼层白名单覆盖；`noBreakfast` 从当天计算排除早餐；休息日无安排显示「今日暂无就餐安排信息」。跨上海午夜先清旧安排。
- 详情支持指定楼层、供餐表、商家展开、菜单、电话与图片预览。整楼休息时内容灰化，列出同校区仍有供餐时段的食堂。无楼层数据不误报休息。
- 实时接口分别降级：失败显示重试提示，保留 release 骨架，清除不可确认的状态。站内图片走 `apiGetBinary`，卸载清理本地文件。
- 地图入口遵循 Web 最终逻辑：食堂有公开楼层或设施时，入口标题改为「楼层与档口」，按钮为「查看供餐详情」，下方为「食堂商户」；其他楼宇保留楼层图。

## 评分

搜索、校车使用同一组件；点击后打开原生评价页，避开 Skyline 抽屉内固定弹层的裁剪与手势问题。入口关闭或提交成功后按 page 记入 `shumap.feature-feedback`。评分请求复用现有 `apiPost` 双通道；不会要求登录。

## 2026-09-26 staging 实际数据验收

staging 已录入 3 个食堂、6 个测试楼层、4 个测试商家、2 张示意图，并激活 `staging-dining-test-20260926`。周末安排有效期 9 月 26–27 日，另有 9 月 28 日工作日例外。真实云托管数据验证了楼层状态、暂停营业、菜单、图片与整楼休息引导。录入前完整数据库导出、测试 SQL 和恢复脚本保存在本地 `tmp/staging-dining/`，未提交数据库备份。

验收发现详情早餐行未应用 `noBreakfast`，已同步修复 Web 与小程序：今日不供早餐时灰化并显示「今日不供应」，隐藏常规早餐时段。

食堂入口在 Web/小程序均采用功能性文案，无设施时不渲染空设施容器。时段栏仅显示当前供餐时段，不再追加日型营业安排后缀。
