# 食堂地图概览与楼层设施

对应 Sketch「新增：食堂和楼层界面」D11–D15。

- 仅 `entityType=building` 且 `kindId=canteen` 使用新概览。白底楼层行保留名称、品类、当日状态和本层商户标签；楼层行进入指定楼层，商户标签复用原商户子视图。
- 替换食堂的旧楼层入口与重复商户列表；普通建筑保持原结构。没有公开楼层的数据保留明确空态。
- 电话、所属单位、地址、图片、简介及通知保留原信息区。未分层或不属于公开楼层的商户在「其他商户」保留。
- 公共设施独立列出楼层与位置；未分层设施显示「楼层待完善」。详情页的「本层设施」只显示所选层，运营状态由 live API 覆盖，读取失败明确提示。
- 详情页底部仍为平面图和本层照片；「查看平面图」进入指定楼层的位图页。休息状态保留灰化，允许查看楼层资料、设施、商户和图片。
- 抽屉按内容测量，封顶 `min(containerHeight * 0.74, 620)`，溢出内部滚动；组件异步更新后重测高度。Web 高度观察器在 release ready 后挂载，修复首次加载未测量而使用默认高度的问题。

- 地点详情打开时临时隐藏入校指南横幅，关闭后恢复，避免高抽屉标题被覆盖。

验证覆盖：两端分组纯函数、未分层/隐藏层商户、设施分层、未知状态、请求独立降级、隐藏后过期请求、跨午夜；浏览器与微信模拟器长字段/滚动/指定楼层/商户跳转/平面图。
